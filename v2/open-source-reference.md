# 飞猪保险智能投保 OS - 开源参考清单

本清单用于提炼产品与交互范式，不照抄任何项目界面。

## AI 助手与会话范式

1. assistant-ui/assistant-ui - 可组合 AI 助手、流式响应、工具调用组件化。
2. ChatGPTNextWeb/NextChat - 轻量多模型助手、低门槛输入和会话管理。
3. deepchat-dev/deepchat - 可嵌入式聊天组件、头像、文件与语音入口。
4. noobnooc/AssisChat - 原生移动 AI 助手、简洁会话和分享入口。
5. Vali-98/ChatterUI - 移动端 LLM 前端、角色会话和参数控制。
6. Mobile-Artificial-Intelligence/maid - 移动端 AI 模型入口、本地/远端切换。
7. dappros/ethora - 聊天、AI 助手、钱包组合式移动体验。
8. ChaasKit - 团队/项目式 AI chat 应用框架。

## 移动电商与交易范式

9. bloomsynth/medusa-mobile-react-native - 商品浏览、分类、购物车、订单追踪。
10. Volm - 开源电商 starter、模块化 catalog/cart/checkout/order。
11. creativetimofficial/argon-react-native - 移动电商卡片、组件组合、轻量 checkout。
12. creativetimofficial/now-ui-react-native - 电商移动模板、简洁卡片与导航。
13. adminmart/modernize-react-lite - 仪表盘信息层级、状态卡和数据摘要。
14. uilibrary/matx-react - 管理端组件体系、状态和表单组件组织。
15. themesberg/volt-react-dashboard - Bootstrap dashboard 卡片、数据与服务状态。

## 出行与场景路径范式

16. Autofleet/locomotion - 出行服务的状态调度和路径选择。
17. vmdt/travel-mobile - 移动旅行预订场景、目的地和行程卡。
18. Felix Travel UI Kit - 酒店、航班、租车、活动等完整旅行模块。
19. georgi/opencode-mobile - 移动任务流、会话、反馈和底部导航。
20. opencode-mobile screenshots - 移动端状态、项目、会话的多屏承接。

## UI Kit 与移动设计系统

21. akveo/kittenTricks - 40+ 屏移动 starter、明暗主题和一致组件。
22. akveo/react-native-ui-kitten - Eva Design System、主题化和通用组件。
23. shoutem/ui - 可组合、可样式化 React Native UI 组件。
24. galio-org/galio - React Native 基础主题和移动组件。
25. creativetimofficial/material-kit - Material Design 的层级、影像和动效原则。
26. NativeKits - 移动优先组件、触控友好和布局组件。

## 吸收为本项目的规则

- 首页不是货架，先给“助手驾驶舱”和一个主行动。
- 分类不前置，诊断结果才出现方案和相关险种。
- 使用图片、状态环、短标签表达，不堆说明。
- 方案只展示 1 个主推和 2 个备选。
- 服务链路要像订单追踪一样可见：保单、预审、续配。
